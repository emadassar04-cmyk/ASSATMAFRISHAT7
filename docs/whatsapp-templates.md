# قوالب رسائل واتساب (Message Templates)

> تُقدَّم للاعتماد من Meta (WhatsApp Manager) قبل الإطلاق. اللغة `ar`. المتغيرات `{{1}}`… بالترتيب. الفئة (Category) المقترحة بين أقواس؛ الاعتماد قد يعيد تصنيفها.
> **لا تحتوي القوالب على بيانات حقيقية**؛ اسم المتجر والفرع والأوقات تأتي كمتغيرات من الإعدادات.
> تُرسل القوالب فقط خارج نافذة 24 ساعة من آخر رسالة للزبون؛ داخل النافذة تُرسل رسائل نصية عادية (WF-06).

## 6) خريطة الحالة ← القالب (WF-07)
| `order.status` / الحدث | القالب |
|---|---|
| new | `order_received` |
| payment receipt uploaded | `payment_awaiting_review` |
| payment confirmed (→ confirmed) | `payment_confirmed` |
| payment rejected | `payment_rejected` |
| in_preparation | `order_in_preparation` |
| ready_for_pickup | `order_ready_pickup` |
| picked_up | `order_picked_up` |
| cancelled | `order_cancelled` |

## 7) ملاحظات اعتماد
- كل قالب بدون روابط مختصرة أو محتوى ترويجي في فئة Utility، وإلا يُعاد تصنيفه.
- يلزم إرفاق أمثلة للمتغيرات عند التقديم.
- حالة كل قالب (Approved/Rejected) تُسجَّل في `settings` (`whatsapp.templates`) ليعرف WF-06 أيها متاح؛ القالب غير المعتمد يُسجَّل فشلاً بدل إرساله.
- فيسبوك ماسنجر وتلجرام لا يحتاجان قوالب (لكن ماسنجر له نافذة 24 ساعة أيضاً).
